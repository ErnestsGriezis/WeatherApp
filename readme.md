# WeatherApp

PHP weather application with city management.

## Features

- View current weather for selected cities
- Add new cities
- Delete existing cities
- Metric / Imperial units switch
- Data stored in Database

## Tech stack

- PHP
- PostgreSQL
- Docker
- jQuery (AJAX)
- OpenWeather API

## Setup

1. Clone repository
2. Create `.env` file with `OPENWEATHER_API_KEY`
3. Run with Docker
4. Open `http://localhost:8080`

## Notes

- Cities are stored in database
- API key is loaded from environment variables
